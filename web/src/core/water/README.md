# 水面渲染

`PondWaterSurface` 用一个 PixiJS WebGL filter 为合成后的鱼塘场景添加水体效果，不运行完整流体模拟。

- 从独立背景纹理估算水域遮罩，避免红白鱼身导致水面效果断开。叶片和岸石区域保留原图，并遮挡经过的鱼；该遮罩是针对当前美术背景的近似，替换背景时需要复核。
- 多方向波面法线驱动像素级折射、柔和天空反射和细微焦散；鱼与池底共同受水面影响。
- 点击产生最多 6 组衰减传播波包，通过折射与明暗波峰表现，取消叠加的圆形描边。
- 最多 4 条固定鱼提供随水深减弱的 V 形尾流，避免鱼群全体产生夸张水迹。
- 滤镜区域固定到视口，正确换算池化纹理坐标、背景 cover 裁剪和点击位置，支持横竖屏及不同渲染分辨率。
- `waterMotion`、`caustics`、`clickRipple` 设置分别控制折射、焦散和点击波纹。

水面保留单一全屏 shader pass。鱼影独立位于鱼层之下，标准和高质量使用低分辨率共享模糊；节能档关闭阴影模糊并降低水面分辨率。鱼的深度同时影响色调、透明度、轻微缩放和遮挡次序。
